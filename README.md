# Angelo Arcillas — Product-Minded Backend Engineer Portfolio

Source code for my personal portfolio and technical blog, showcasing backend engineering work, system design architectures, and technical articles.

---

## 🛠️ Tech Stack

- **Framework:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS v4, `@ad-technology-inc/design-system`
- **Content & Visuals:** `react-markdown` (articles), `mermaid` (architecture diagrams), `lucide-react` (icons)

---

## 📂 Project Structure

```text
src/
├── components/    # Common UI, layout sections, portfolio showcases, and calculators
├── css/           # Design system tokens and Tailwind styling layers
├── data/          # Portfolio projects, system designs, articles, and resume data
├── pages/         # Page routes (Home, Solutions, System Design, Articles, Resume)
├── App.tsx        # Application shell and routing setup
├── main.tsx       # Entry point
└── routes.ts      # Route constants
```

---

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
