In high-throughput relational backends, naive ORM usage quickly leads to excessive memory consumption and database CPU exhaustion.

## High-Performance Relational Strategies

- **Multi-Hop Relationships**: `hasManyThrough` compiles complex domain relationships into a single `INNER JOIN`, eliminating intermediate entity hydration.
- **SQL Aggregations via `selectRaw`**: Computes dynamic metrics inside the database rather than hydrating PHP objects into server RAM.
- **Memory-Safe Streaming**: `chunkById()` and `cursor()` process large datasets in indexed batches, ensuring predictable memory usage under heavy query loads.
