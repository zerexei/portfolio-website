Dagre implements a variation of the Sugiyama framework to position directed graphs cleanly.

## Sugiyama Layout Pipeline

1. **Cycle Removal**: Temporarily reverses feedback loops to convert arbitrary graphs into DAGs.
2. **Layer Assignment (`network-simplex`)**: Solves a minimum-cost network flow problem to minimize edge spans:
   `min sum(w(e) * (rank(v) - rank(u)))`
3. **Crossing Minimization**: Reorders nodes within layers using heuristic sweeps to minimize edge intersections.
4. **Coordinate Assignment**: Allocates concrete $(X, Y)$ screen coordinates while honoring padding and separation constraints.
